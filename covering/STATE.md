# Covering designs — track state

**Цель.** Улучшать best-known covering numbers C(v,k,t) (минимум k-подмножеств v-множества, накрывающих все t-подмножества). Один улучшенный инстанс = реальный верифицируемый результат. Выбрано вместо weak Schur по уроку: **поле из многих открытых проверяемых инстансов**, где решает систематичность+continuity+дешёвая проверка, а не суперкомпьютер на одной игле.

## Где результат записывается (важно — изменилось)
- **LJCR (ljcr.dmgordon.org) ЗАКРЫТ для новых записей** с 1 марта 2026, сайт отключат в 2026.
- **Данные best-known** заархивированы: Zenodo `10779737` → `data/coverdata.json` (6.7MB: size=best UB, low_bd=recorded LB). По ним точно проверяю «побила ли запись».

## Поле
- coverdata.json: **8771 записей, 6844 с зазором (size>low_bd)**. 26 трактабельных gap=1 (v≤25, t≤3, size≤40).
- gap=1 = найти покрытие размера low_bd → новый рекорд + оптимальность.

## Аппарат (covering/)
- `verify.py` — ГЕЙТ: `verify_covering(blocks,v,t)` + `schonheim(v,k,t)`. Валидирован (7 примеров Schönheim + gate).
- `scan_gaps.py` — сканер зазоров по coverdata.json.
- `sa.py` — simulated annealing (стандарт Nurmela-Östergård): фикс m блоков, минимизируй непокрытые t-подмножества. ✅ воспроизводит best=10 для C(18,11,3).
- `batch_attack.py` — свип gap=1 целей.

## Дисциплина
Воспроизвести best_known (валидация SA) → атаковать best−1 → ГЕЙТ → сохранить → перепроверить adversary → подать.

## Стратегия (ключевое)
Наивный SA за 40-100с вряд ли побьёт 30-летние SA-записи LJCR. **Мой эдж — структурированные конструкции, где cleverness бьёт брутфорс** (как модулярный скелет в weak Schur): циклические (орбиты Z_v), групповые (Frobenius для prime-power v), разностные. Генерический SA их не достигает эффективно. План: свип SA → где близко (мало непокрытых) → вернуться с ЦИКЛИЧЕСКОЙ конструкцией (искать базовые блоки + орбиты группы). Один структурный выигрыш = реальный рекорд.
